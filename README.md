## 🚀 Live Demo & Deployment

This repository is configured for **GitHub Pages 24/7 Free Hosting**.

### Quick Deployment Instructions:

1. **Push to GitHub**:
   ```bash
   git init -b main
   git add .
   git commit -m "Deploy Abhishek Parmar Portfolio"
   git remote add origin https://github.com/abhi963411-ops/portfolio.git
   git branch -M main
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/abhi963411-ops/portfolio`
   - Click **Settings** > **Pages** (left sidebar).
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Choose branch `main` and folder `/ (root)`.
   - Click **Save**.

🎉 Your website will be live 24/7 at:
👉 **`https://abhi963411-ops.github.io/portfolio`**

## 🛠️ Local Development

To run the site locally on your machine:

```bash
# Clone repository
git clone https://github.com/abhi963411-ops/portfolio.git
cd portfolio

# Launch local server using Python
python -m http.server 8085
```
Then open `http://localhost:8085` in your web browser.
